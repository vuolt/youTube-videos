# Video 1: Every Sci-Fi Shortcut Is Secretly a Time Machine

Why faster-than-light travel of any kind, including warp drives and wormholes, would also be a time machine.

- `script.md`: the voice-over script (69 numbered lines in 9 sections), the fact-check notes, and the references for the video description. Edit lines here, then rebuild.
- `scenes.js`: the 9 scenes. Every animation is tied to a script line, so the video re-times itself to the recordings.

Build it from the repository root with `./make.sh 01`, and record the voice with `python3 record.py`. The top-level [README](../README.md) has the setup, and [STYLE.md](../STYLE.md) the conventions.
